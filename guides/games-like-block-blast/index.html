Games like Block Blast that work offline

Block Blast made the block puzzle popular again, and the search that follows it is always the same: what else is like this, and does it work without internet. This is a short, honest list from a studio that makes one of these games, so read it with that in mind.

What to look for, before the list

Three things matter more than graphics, and all three are easy to check in two minutes of play.

First, whether the game is playable offline. Many block puzzles load an ad before the board appears, which means no connection, no game. Second, whether the game interrupts a round. In a game designed for a five minute break, an interstitial at the wrong moment is the whole session. Third, whether the piece set is fair. If the game hands you a three by three square with no space for it, that is not difficulty, that is a slot machine.

The list

Block Blast. The one everyone arrives from. Bright, fast, generous with combos, and the reference point for the genre. It is free with advertising, and the ad load is the main complaint in its reviews.

Woodoku. Wooden look, a nine by nine grid, and a sudoku influence in the way rows and columns clear. Calmer than Block Blast, and a good choice if you want something that looks like a tabletop game.

Blockudoku. Takes the block puzzle and adds a sudoku rule: full nine cell squares also clear. It rewards planning across the whole board rather than one edge, which makes it a harder game to learn and a more interesting one once you have.

1010!. The oldest of the modern crop, and still the cleanest. No combos, no power ups, just placing pieces and clearing lines. If you want to learn the shape of the genre without any noise, start here.

Brickwise. Ours. Same rules as the genre, built to run offline with no round interrupted by an ad, and no purchase that changes how the game plays. We made it because the games we liked kept stopping to sell us something.

Why offline is the feature that matters most

For a lot of players, a puzzle game is what you open in a queue, on a bus, or in a room where the wifi does not reach. If the board needs a server to appear, the game is not there when you need it.

Offline also changes what the app can promise. A game that never calls a server does not need to know anything about you to work, which is the reason our studio can keep the promise that most free games quietly break.

How to choose between them

If you want maximum excitement and do not mind advertising, Block Blast is the obvious pick. If you want quiet, Woodoku. If you want a real puzzle with a sudoku rule layered on top, Blockudoku. If you want to learn the genre properly, 1010!.

And if the thing that bothers you is being interrupted, try the one from the small studio. That is the only difference we can honestly claim.

Getting better at any of them

Whatever you pick, the skill is the same: keep the empty space rectangular, keep a three by three square free for the large piece, and never let a single square sit alone for more than two turns. Our block puzzle strategy guide explains each of those with the reasoning behind it.

Questions people ask

Are all of these free?

Yes, they are free to install. Some show advertising, some offer optional purchases.

Which ones work with no internet?

All of the games listed here can be played offline once installed, with the caveat that advertising supported games may behave differently without a connection. Brickwise was built to need no connection at all.

Is Brickwise a copy of Block Blast?

It uses the same long established block puzzle rules, which predate both games. The difference is in how it handles advertising and offline play, not in the rules.
